# Captain's Compass v1.1.0

## Added

- `source-code-context` Skill: search real package/repository source before
  guessing APIs, with preferred-optional
  [opensrc](https://github.com/vercel-labs/opensrc)
- `code-structure-cleanup` Skill: post-feature service-layer cleanup under a
  separate approved implementation plan
- `review-fix-loop` Skill: iterate on PR/review feedback until merge-ready or a
  human decision is required
- `docs/integrations/opensrc.md`: setup, usage, and fallback guidance
- Agent install/activation prompts and expanded product onboarding guidance
- Recorded sandbox failure-test evidence

## Changed

- Captain's Compass now includes twenty Skills
- Doctor and installer tests validate the expanded Skill set
- Project memory and README reflect the v1.1.0 workflow
