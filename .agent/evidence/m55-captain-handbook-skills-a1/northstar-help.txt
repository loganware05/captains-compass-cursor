NorthStar launcher — Skills Learning Loop + Code Reviewer (one product)

Usage:
  northstar help
  northstar skills <subcommand> …
  northstar review …
  northstar review ingest-agentic-security …
  northstar intent <subcommand> …
  northstar outcomes <subcommand> …
  northstar repair <subcommand> …
  northstar precision <subcommand> …
  northstar context <subcommand> …
  northstar evaluate <subcommand> …
  northstar learn <subcommand> …
  northstar instructions <subcommand> …
  northstar prompt-eval <subcommand> …
  northstar policy <subcommand> …
  northstar status <subcommand> …
  northstar provenance <subcommand> …
  northstar examples <subcommand> …

Surfaces (one-line purpose):
  skills      Learning Loop — refresh TI, learn, promote, sync-ledger, route-agents
  review      Code Reviewer — detect→investigate→verify→report (evidence-only default);
              optional ingest-agentic-security (M39, allowlist opt-in)
  intent      Export / normalize intent packs for review (never Captain approval)
  outcomes    Record finding triage → Experience (+ optional proposal-only routing)
  repair      FIND→PROVE→packet from verified findings (never auto-merge)
  precision   Aggregate finding outcomes into precision ledger / dashboard
  context     Filesystem-gated context (M40) — build inode store + walk context routes
  evaluate    Behavior evaluation (M46) — observe-only; requires COMPASS_BEHAVIOR_EVAL_ENABLED=1
  learn       Behavior pattern learning (M47) — proposal-only; requires COMPASS_BEHAVIOR_LEARN_ENABLED=1
  instructions Instruction registry + PICCO composer (M48) — proposal-only; requires COMPASS_INSTRUCTIONS_ENABLED=1
  prompt-eval Prompt evaluation harness (M49) — eval-only; requires COMPASS_PROMPT_EVAL_ENABLED=1
  policy      Policy promotion lifecycle (M50) — requires COMPASS_POLICY_PROMOTE_ENABLED=1
  status      Project Overseer (M51/M52) — read-oriented; requires COMPASS_STATUS_ENABLED=1
  provenance Execution provenance ledger (M53) — requires COMPASS_PROVENANCE_ENABLED=1
  examples   Behavior exemplars (M53) — proposal-only; requires COMPASS_PROVENANCE_ENABLED=1

Topology:
  CONTROL  = directory containing this launcher (captains-compass-cursor)
  --repo   = product/sandbox repository root (maps to --repo-root on underlying scripts)
  Product installs get docs/Skills via install.sh — control scripts stay in CONTROL

Docs:
  docs/INDEX.md                 Operator index (Learning Loop + Code Reviewer)
  docs/PRODUCT_ONBOARDING.md    Install into a product repo
  docs/integrations/code-reviewer.md
  docs/integrations/linear-skills-learning-loop.md
  docs/integrations/decision-provider.md

Locks:
  Never clones or executes starred repositories.
  Never installs Skills without --captain-approved on promote.
  Linear sync never originates Captain approval.
  Code review (M27+) defaults to evidence-only; M30 draft posting is opt-in.
  Agentic Security ingest (M39) is opt-in + allowlist-gated; hermetic default unchanged.
  Intent packs (M29) never originate Captain approval.
  Finding outcomes (M31) write Experience; RoutingProposal stays proposal-only.
  Repair loop (M32 / B4) is Captain-gated, verified-only, never auto-merges.
  Precision ledger (M33 / B5) never auto-applies reputation / priority.
  Behavior evaluate (M46) is observe-only; requires COMPASS_BEHAVIOR_EVAL_ENABLED=1;
  never mutates routing, Skills, instructions, reputation, or authority.
  Behavior learn (M47) is proposal-only; requires COMPASS_BEHAVIOR_LEARN_ENABLED=1;
  never activates Policies or mutates Skills/routing/instructions/authority.
  Instructions (M48) are proposal-only; requires COMPASS_INSTRUCTIONS_ENABLED=1;
  never activates Policies or writes live .cursor/Skills/routing/authority.
  Prompt-eval (M49) is eval/proposal-only; requires COMPASS_PROMPT_EVAL_ENABLED=1;
  never promotes instructions or mutates .cursor/Skills/routing/authority.
  Policy (M50) requires COMPASS_POLICY_PROMOTE_ENABLED=1; Active compose-include
  requires COMPASS_POLICY_APPLY_ENABLED=1; never auto-writes .cursor/ or grants
  approved_for_execution.
  Status (M51) requires COMPASS_STATUS_ENABLED=1; read-oriented / proposal-only;
  never approves plans, promotes Skills/Policies, or auto-rewrites project memory.
  Prompt-eval (M54) may set COMPASS_PROMPT_EVAL_INCLUDE_EXEMPLARS=1 to append
  curated .agent/examples/ as cases (default off; never auto-promotes).
  Provenance/examples (M53) require COMPASS_PROVENANCE_ENABLED=1; proposal-only;
  never auto-promote Skills/Policies or grant approved_for_execution.
